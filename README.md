# Анализ продаж мороженого и сезонности спроса

## Описание
Прикладное цифровое решение на Python для анализа продаж мороженого. Программа выявляет сезонные пики и спады спроса на основе исторических данных.

## Функциональность
- Загрузка данных из CSV-файла.
- Очистка данных (удаление пустых строк и проверка форматов).
- Расчет выручки по месяцам.
- Построение графика сезонности.
- Вывод текстового отчета (пик и спад продаж).

## Как запустить
1. Установите зависимости:
   pip install -r requirements.txt
2. Запустите программу:
   python app.py

## Используемые технологии
- Python 3
- Pandas (обработка данных)
- Matplotlib (визуализация)
